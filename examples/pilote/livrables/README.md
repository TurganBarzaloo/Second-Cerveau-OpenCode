# Livrables

Ce dossier reçoit les **fichiers produits** : documents rédigés, exports,
images, maquettes. L'agent y écrit librement — c'est le seul endroit du vault
prévu pour ça.

Un livrable n'est ni une source ni une synthèse :

| | Rôle | Qui écrit |
| --- | --- | --- |
| `sources/` | originaux reçus, preuves de ce qu'ils affirment | personne — immuables |
| `syntheses/` | ce que l'IA a compris des sources, chaque fait référencé | l'agent |
| `livrables/` | ce que le projet produit pour l'extérieur | l'agent |

La fiche projet reste l'autorité sur l'état d'avancement : un fichier présent ici
ne signifie pas qu'une tâche est faite. C'est la fiche qui le dit.

Dans ce pilote fictif, le livrable attendu est la fiche d'accueil de l'atelier
(tâche `P001-T03`). Elle n'est pas fournie : c'est vous qui la produirez en
suivant [COMMENCER-ICI.md](../COMMENCER-ICI.md).
